# Python_test

这是一个标准的 Python 测试项目结构。

## 目录结构
- `src/`: 存放项目的核心源代码
- `tests/`: 存放项目的测试代码
- `requirements.txt`: 项目依赖包列表

## 快速开始

1. 创建并激活虚拟环境：
```bash
python -m venv venv
# Windows
.\venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 运行主程序：
```bash
python src/main.py
```

4. 运行测试：
```bash
pytest
```
